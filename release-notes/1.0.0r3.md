# UV-K5 V1 1.0.0r3（候选测试版）

## 兼容性

- 仅用于 UV-K5 V1，硬件 DP32G030 + BK4819；禁止用于 UV-K1 / UV-K5 V3。
- 内嵌版本：`1.0.0r3`；源码提交和编译器见包内 `BUILDINFO.txt`。

## 变化

- README 的 Radio Remote CAT V3 协议说明改用官网地址，并更新上游说明文字和编译示例。
- 保留上游 Git 历史，将个人维护内容整理为一个新提交；本版本替代旧的 `1.0.0r2` 候选测试版。
- 固件业务功能与 `1.0.0r2` 一致，继续提供角色化 CAT、屏幕推送、普通按键、带租约 PTT、静噪控制及 UART 协议共存、残包超时和 AT 行回显。

## 使用和验证

- 刷机前备份本机数据；核对硬件并执行 `shasum -a 256 -c SHA256SUMS`。
- 发布校验：CAT 与 UART 解析回归测试、干净 Docker 编译、镜像尺寸限制、内嵌版本、ZIP 完整性和 SHA-256；构建提交、工具链及尺寸见包内 `BUILDINFO.txt`。
- 实机验证：待维护者完成；当前不宣称已完成收发、屏幕、按键、PTT 租约或断线恢复的实机验证。
- 已知限制：不提供软件电源开关；不包含 CHIRP 驱动、校准备份或恢复工具。
- 保留上游许可证、作者致谢和第三方声明。
