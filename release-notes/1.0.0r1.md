# UV-K5 V1 1.0.0r1（候选测试版）

## 兼容性

- 仅用于 UV-K5 V1，硬件 DP32G030 + BK4819；禁止用于 UV-K1 / UV-K5 V3。
- 内嵌版本：`1.0.0r1`；源码提交和编译器见包内 `BUILDINFO.txt`。

## 变化

- 整理 Radio Remote CAT V3 衍生固件的首次 GitHub 候选发布流程。
- 支持角色化 CAT、屏幕推送、普通按键、带租约 PTT 和静噪控制。
- MAIN 模式支持独立收发频率和亚音，本地修改推送状态。
- 提供 UART 协议共存、残包超时和 AT 行回显。

## 使用和验证

- 刷机前备份本机数据；核对硬件并执行 `shasum -a 256 -c SHA256SUMS`。
- 自动验证：以对应 GitHub Actions 运行日志及包内构建信息为准。
- 实机验证：待维护者完成；当前不宣称已完成收发、屏幕、按键、PTT 租约或断线恢复的实机验证。
- 已知限制：不提供软件电源开关；不包含 CHIRP 驱动、校准备份或恢复工具。
